👻 Ghost Action

自分の動きを録画して「ゴースト」を作り、足場にしてゴールを目指すアクションパズルゲーム！

モードを選択してください

⏸ メニュー

このメニューを開いている間も、タイマーやステージ内の動きは止まりません。

📖 遊び方・ルール

1. ゲームの目的

自分の動きを「録画」してゴーストを作り、そのゴーストを「足場」にして高いところや障害物を乗り越え、一番奥のゴール（オレンジ色の扉）を目指すアクションパズルゲームです！

2. 基本操作

  • 移動： 左右の矢印ボタン（または A / Dキー）
  • ジャンプ： 上矢印ボタン または W / Kキー（またはW/Sの組み合わせでななめジャンプも可能）

3. 💡 録画とゴーストの使い方のコツ

そのままでは届かない高い崖やトゲの上に行くために、以下の手順を使います：

  • ① [ 🔴 録画 ] ボタンを押す： 自分の動きの録画が始まります。ジャンプして足場に飛び乗るなどの動きをさせます。
  • ② もう一度 [ 🔴 録画 ] ボタンを押す（完了）： 録画がストップし、自分の動きをコピーした「ゴースト」が誕生します。
  • ③ [ ▶ 再生 ] ボタンを押す： ゴーストが動き出します。動いている最中にもう一度 [ ▶ 再生 ] ボタンを押すと、その瞬間でゴーストが「固定された足場」に変形します！
  • ④ 足場を使った攻略： 固定されたゴーストの上に飛び乗ることで、通常では届かない高いエリアへ進めるようになります。

4. その他のボタン機能

  • Q / E（減速・加速）： 再生されるゴーストのスピードを調整できます。
  • C（リセット）： ゴーストやステージ状況を最初の状態に戻します。
  • ⇄（入替）： 左右のコントローラーの配置を入れ替えます（利き手に合わせられます）。
